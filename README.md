# Diep.io-Fan-Project
Javaの標準ライブラリ（Swing / AWT）のみを駆使し、人気Webゲーム『Diep.io』のシステム、物理、描画、そして高度なゲームモードとAI（BOT）までを徹底的に再現したフルスクラッチの2Dアクションシューティングゲームです。

## 概要
外部のゲームエンジンに一切頼らず、グラフィックの最適化（自作カメラ・バッファリング）、時間ベースのゲームループ、そして敵戦車の意思決定アルゴリズム（AI）にいたるまで、すべてJavaの標準機能だけで実装しました。

- **開発環境:** Java (JDK [バージョン]) / Java Swing
- **外部ライブラリ依存:** なし（完全フルスクラッチ）
- **パフォーマンス:** 60FPS（時間差によるリアルタイム制御）
- **プレイ動画 / キャプチャ:** (ゲームモード選択や、BOTとの激しい戦闘、ズームイン/アウトのGIFアニメーションを配置)

---

## 🌟 実装したコア機能・ゲームモード

### 1. 充実の7つのゲームモード
オンライン対戦さながらの戦場をオフラインで再現するため、本家の主要モードを網羅しました。
- **FFA (Free For All):** 全員が敵のバトルロイヤル。
- **2Teams / 4Teams:** チームに分かれて領土とスコアを競う集団戦。
- **Domination:** ステージ上の4つの巨大な砲台（Dominator）をチームで奪い合うモード。
- **Tag:** 敵を倒すと自チームに反転する、逆転要素のあるチーム戦。
- **Mothership:** 各チームの巨大母船（Mothership）を守りつつ、敵の母船を破壊するモード。
- **Sandbox:** すべての戦車に自由に進化でき、検証やコマンドを試せるソロモード。

### 2. 進化システム ＆ UI
- **レベルアップとステータス選択:** 図形や敵の撃破で経験値を獲得し、パラメータを強化可能。
- **進化ツリー:** **`T`キー**を押すことで、画面上に現在の戦車の進化ツリーを視覚的に表示するUIを実装。

### 3. 自作AI（BOT）による高度な立ち回り
オンライン未対応を補って余りある、強力なBOTアルゴリズムを自作しました。
- **偏差射撃:** プレイヤーの移動速度と弾速を計算し、未来の位置を予測して狙撃する数理ロジック。
- **弾の回避・立ち回り:** 飛んでくる弾幕の危険度を察知して回避行動を取り、状況に応じてステータスを自動選択・強化する意思決定AI。

## 🛠️ 技術的工夫と最適化（アーキテクチャ）

### 1. 自作Cameraクラス ＆ BufferedImageによる超高速描画
描画負荷を極限まで下げるため、メモリ上に `BufferedImage` を確保してバックバッファとして描画し、一括で画面に転送（`drawImage`）するダブルバッファリングを最適化。
さらに、**自作の `Camera` クラス**により、プレイヤーを中心に据えた座標変換や、戦車の成長・状況に応じた**視野のダイナミックなズーム（拡大・縮小）変動**を滑らかに実現しました。

### 2. リアルタイム差（デルタタイム）による60FPS制御
フレームレートの変動にゲームスピードが依存しないよう、フレーム数ベースではなく、**「前回のフレームからの経過時間（ミリ秒単位の差分）」**を元に移動や物理演算を進める処理を実装。これにより、どのような環境でも一定の速度で滑らかに動作します。

### 3. 計算負荷の最適化（空間淘汰）
大量の弾やオブジェクトが飛び交う本作において、**画面外（視野外）のオブジェクトの当たり判定処理をスキップ**するロジックを実装。CPUの計算資源を節約し、常時安定した60FPSを維持します。

## 🎮 操作方法・ゲームの終了

- **移動:** `W` `A` `S` `D` キー
- **照準・射撃:** マウス移動 ＆ クリック
- **進化ツリー表示:** **`T` キー**
- **ゲームの終了:** 画面右上の **`×` ボタン** を押すことで安全にアプリケーションを終了します。
